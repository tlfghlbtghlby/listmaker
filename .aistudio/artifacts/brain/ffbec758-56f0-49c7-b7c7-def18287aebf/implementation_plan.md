# نظام الشفتات المسبقة الإعداد، حظر البيع بدون شفت، وإدارة المشرفين المتعددين

خطة تطوير وتحديث شاملة لنظام الورديات (الشفتات) وجلسات العمل، تضمن ضبط الرقابة المالية ومنع أي عمليات بيع في جلسة الموظف ما لم يكن هناك شفت نشط ومفتوح تم بدؤه عبر شفت معد مسبقاً برمزه الخاص، مع تمكين الأدمن من إضافة عدة مشرفين برموز وصلاحيات مستقلة تظهر في قائمة التبديل بين الجلسات.

---

> [!IMPORTANT]
> **القرارات المؤكدة بناءً على إجابات المستخدم:**
> 1. **صلاحية المشرف في إعداد الشفتات**: السماح للمشرف بإعداد وتعديل الشفتات المسبقة إذا منحه الأدمن هذه الصلاحية (`canConfigureShifts`).
> 2. **المشرفون المتعددون**: إمكانية إضافة أكثر من مشرف من قبل الأدمن، ولكل مشرف اسمه ورمزه الخاص، مع إدراج جلسات المشرفين المتعددين في زر اختيار الجلسة.
> 3. **شرط بدء الشفت**: لا يتم بدء أي شفت إلا باختيار شفت معد مسبقاً له اسمه ورمزه السري الخاص مع استمرار خيار النقد الافتتاحي وبقاء عداد الوقت النشط للشفت.
> 4. **منع البيع في جلسة الموظف**: إيقاف وحظر إتمام أي عملية بيع أو إصدار فواتير في جلسة الموظف إذا لم يكن هناك شفت جارٍ.

---

## 1. نظرة عامة وتجربة المستخدم (Overview & Experience)

### تجربة بدء الشفت الجديد:
- بدلاً من الفتح العشوائي للشفت، يفتح الموظف أو المشرف نافذة **بدء الشفت**.
- تظهر قائمة بالشفتات المجهزة مسبقاً (مثل: *شفت الصباح - الصالة*، *شفت المساء - الكاشير الرئيسي*، إلخ).
- يقوم المستخدم باختيار الشفت المطلوب وإدخال **الرمز السري الخاص بهذا الشفت**.
- إدخال النقد الافتتاحي للصندوق (اختياري) ثم الضغط على **بدء الشفت**.
- ينطلق **عداد الوقت اللحظي** للشفت ويظهر في شريط الرأس وتفاصيل الشفت.

### تجربة الموظف في نقطة البيع (POS):
- في حال كانت الجلسة الحالية هي **جلسة موظف (Employee)** ولا يوجد شفت مفتوح:
  - تظهر بطاقة تنبيه ذكية أعلى شاشة البيع: *"⚠️ لا يوجد شفت نشط حالياً - يُرجى بدء شفت معد مسبقاً لمباشرة البيع"*.
  - يتم قفل زر "حفظ وطباعة الفاتورة" وزر "بيع مباشر / آجل" مع رسالة إرشادية وزر مباشر يفتح نافذة بدء الشفت.
- بمجرد بدء الشفت، تنفتح إمكانية البيع فوراً وتُرصد الفواتير والمواد المباعة بدقة تحت هذا الشفت.

### تجربة إدارة المشرفين المتعددين والشفتات المسبقة:
- في إعدادات النظام ولوحة المشرفين:
  - يستطيع الأدمن إضافة وتعديل وحذف المشرفين: تحديد (الاسم، الرمز السري، وصلاحية إعداد الشفتات `canConfigureShifts`).
  - يستطيع الأدمن أو المشرف المخوّل إعداد قوالب الشفتات: (اسم الشفت، الرمز السري، الملاحظات الافتراضية).
- عند الضغط على زر **التبديل بين الجلسات (Session Badge)**:
  - يظهر خيار جلسة الأدمن، وجلسة الموظف، وبطاقات منفصلة لكل مشرف مسجل (مثال: *"مشرف: أحمد الكرخي"*، *"مشرف: سرمد"*).
  - عند اختيار مشرف معين، يطلب النظام إدخال الرمز السري الخاص بذلك المشرف للتحقق منه والتبديل إلى جلسته مع تطبيق صلاحياته.

## 2. التصميم البصري وعناصر الواجهة (UI/UX)

- **بطاقات المشرفين في نافذة تبديل الجلسات**: أسلوب عصري متناسق مع الواجهة، مع أيقونة درع ذهبية/بنفسجية مميزة لكل مشرف مع اسمه وصلاحية إعداد الشفتات الخاصة به.
- **نافذة اختيار الشفت المسبق**: شبكة كروت أنيقة لاختيار الشفت المطلوب بضغطة واحدة، متبوعة بحقل إدخال رمز الشفت الآمن (مع لوحة أرقام سريعة PIN Pad اختيارية).
- **حالة قفل البيع في نقطة البيع**: شريط تحذيري هادئ غير مزعج من درجات الكهرمان والعنبر (`amber-500/10`) يوضح بلغة واضحة سبب التعليق مع زر سريع `[بدء شفت معد مسبقاً]`.
- **عداد وقت الشفت**: استمرار عمل العداد الدقيق التنازلي/التصاعدي الذي يعرض الساعات والدقائق والثواني المنقضية منذ انطلاق الشفت.

## 3. القرارات التقنية وهندسة البيانات (Architecture & Strategy)

```
┌─────────────────────────────────────────────────────────────┐
│                      Admin / Store Owner                    │
│      - إعداد المشرفين المتعددين (الاسم + الرمز + الصلاحيات)     │
│      - إعداد قوالب الشفتات المسبقة (Preset Shifts)           │
└──────────────────────────────┬──────────────────────────────┘
                               │
            ┌──────────────────┴──────────────────┐
            ▼                                     ▼
┌─────────────────────────┐             ┌─────────────────────────┐
│     Supervisor(s)       │             │   Employee Session      │
│  - الدخول برمز المشرف   │             │  - لا يمكن البيع بدون   │
│  - إعداد الشفتات (إن   │             │    شفت جارٍ              │
│    مُنح الصلاحية)        │             │  - بدء شفت عبر اختيار   │
└─────────────────────────┘             │    قالب مسبق + رمزه     │
                                        └────────────┬────────────┘
                                                     ▼
                                        ┌─────────────────────────┐
                                        │     Active Shift        │
                                        │  - عداد وقت الشفت شغال  │
                                        │  - رصد المبيعات والأرباح │
                                        └─────────────────────────┘
```

### تعديلات بنية البيانات (Types & Models):

1. **نموذج الشفت المسبق الإعداد `PresetShift`**:
   ```typescript
   export interface PresetShift {
     id: string;
     name: string; // اسم الشفت (مثلاً: شفت الصباح، شفت المساء)
     code: string; // الرمز السري الخاص بالشفت لبدئه
     notes?: string;
     createdAt: string;
     createdBy: string;
   }
   ```

2. **نموذج المشرف المخصص `StoreSupervisor`**:
   ```typescript
   export interface StoreSupervisor {
     id: string;
     name: string; // اسم المشرف
     pin: string; // الرمز السري للمشرف
     canConfigureShifts: boolean; // هل يملك صلاحية إعداد الشفتات المسبقة
     permissions?: Partial<RolePermissions>;
     createdAt: string;
   }
   ```

3. **تحديث `StoreSettings`**:
   - إضافة مصفوفة `supervisors: StoreSupervisor[]`.
   - إضافة مصفوفة `presetShifts: PresetShift[]`.

4. **تحديث `Shift` و `activeShift`**:
   - ربط الشفت المنطلق بمعرف واسم القالب: `presetShiftId` و `presetShiftName`.

5. **التحقق من البيع في `POSView.tsx`**:
   - إذا كان `sessionRole === 'employee'` ولا يوجد `activeShift`:
     - تعطيل زر إتمام البيع، وإظهار تنبيه يمنع حفظ الفاتورة مع فتح نافذة بدء الشفت.

6. **تحديث `SessionSwitchModal.tsx` و `SessionBadgeButton.tsx`**:
   - دعم التبديل إلى مشرفين متعددين وعرض اسم المشرف النشط حالياً في الهيدر والجلسة.

## 4. خطوات التنفيذ المجدولة (Execution Plan)

1. **تحديث نماذج البيانات (`src/types.ts`)**:
   - إضافة واجهات `PresetShift` و `StoreSupervisor`.
   - توسيع `StoreSettings` لدعم قائمة المشرفين وقائمة الشفتات المسبقة وصلاحية `canConfigureShifts`.

2. **تحديث سياق التطبيق (`src/context/AppContext.tsx`)**:
   - دوال إدارة قوالب الشفتات: إضافة، تعديل، حذف قالب شفت مسبق الإعداد.
   - دوال إدارة المشرفين: إضافة، تعديل، حذف مشرف مع رمزه وصلاحياته.
   - ترقية `startShift` لتقبل `presetShiftId` والتحقق من رمزه السري.
   - ترقية `switchSession` لتدعم التحقق من رموز المشرفين المتعددين وحفظ هوية المشرف النشط.

3. **تطوير واجهة بدء الشفت (`StartShiftModal.tsx`)**:
   - عرض قائمة الشفتات المعدة مسبقاً للاختيار منها.
   - حقل إدخال الرمز السري الخاص بالشفت المحدد للتحقق من صحته قبل البدء.
   - الحفاظ على حقل النقد الافتتاحي للصندوق ومؤقت الشفت.

4. **تطوير واجهة إعداد الشفتات والمشرفين في الإعدادات وتبويب الشفتات**:
   - إضافة قسم مخصص لإدارة الشفتات المسبقة الإعداد (للأدمن أو المشرف المخوّل).
   - إضافة قسم مخصص لإدارة المشرفين المتعددين في إعدادات الجلسات (خاص بالأدمن).

5. **تحديث شاشة البيع (`POSView.tsx`)**:
   - إضافة قفل الرقابة: منع الموظف من البيع إذا لم يكن هناك شفت جارٍ.
   - إظهار شريط تنبيه واضح مع زر مباشر لبدء شفت معد مسبقاً.

6. **تحديث نافذة وزر الجلسات (`SessionBadgeButton.tsx` و `SessionSwitchModal.tsx`)**:
   - إظهار قائمة المشرفين المتعددين بأسمائهم في نافذة التبديل.
   - التحقق من الرمز السري الخاص بكل مشرف عند اختياره.

7. **الفحص والتحقق الكامل**:
   - إجراء التحقق البرمجي عبر `compile_applet` و `lint_applet` للتأكد من خلو المشروع تماماً من أي أخطاء.
